## 🚀 Projetos Desenvolvidos

### 📋 To-Do List
Aplicativo de lista de tarefas com gerência de estado nativa do Flutter.

### 🔐 Login App
Projeto completo com Splash Screen, Login Page, LoginController, navegação entre telas, componentes reutilizáveis, Repository Pattern, consumo de API REST, passagem de parâmetros via `ModalRoute` e persistência de sessão com `SharedPreferences`.

### 🎬 Movie APP
Aplicativo de filmes consumindo uma API externa, com layout de cards, animação Lottie no carregamento, Hero Animation na transição para a tela de detalhes e barra de pesquisa funcional.

## 🛠 Tecnologias e Conceitos Abordados

- Flutter & Dart
- Widgets nativos (PageView, Drawer, Scaffold, etc.)
- Widgets personalizados e componentes reutilizáveis
- Gerência de estado nativa (`setState`)
- Navegação entre telas (`Navigator`, `ModalRoute`)
- Consumo de API REST com o pacote `http`
- Padrão de arquitetura MVC
- Repository Pattern
- Persistência local com `SharedPreferences`
- Animações: Lottie e Hero Animation
- Barra de pesquisa (Search Bar)

## ▶️ Como Executar

1. Certifique-se de ter o Flutter instalado. Caso não tenha, siga a [documentação oficial](https://docs.flutter.dev/get-started/install).

2. Clone o repositório:
   ```bash
   git clone https://github.com/heitorhidalgo/flutter-nv1.git
   ```

3. Acesse a pasta do projeto:
   ```bash
   cd flutter-nv1
   ```

4. Instale as dependências:
   ```bash
   flutter pub get
   ```

5. Execute o projeto:
   ```bash
   flutter run
   ```
